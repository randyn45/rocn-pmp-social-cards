# rocn-pmp-social-cards

Public media host for Peptide Manager Pro / ROCN LLC social cards and reels.

Buffer and other schedulers require publicly fetchable image URLs; this repository serves that
role. Migrated 2026-08-26 from `gs://rocn-pmp-social-cards` (Google Cloud Storage), whose free
trial lapses 2026-08-29.

**URL form:** `https://raw.githubusercontent.com/randyn45/rocn-pmp-social-cards/main/<path>`
Paths are unchanged from the previous GCS bucket, so the old and new URLs differ only by prefix.

Contents are social-media artwork intended for public distribution. Internal specs, manifests and
SEO data that lived in the old bucket were deliberately **not** migrated, nor was one superseded
asset withdrawn for compliance reasons.
